Nectar

A whole desktop for KolibriOS — written in Python, shipped as one native executable.

The taskbar with its launcher, the notification area and its flyouts, notifications that sink into a bell by the clock, the desktop's shortcuts, Alt+Tab, a Run panel. Every line of it is Python, compiled by plainpy into a 158 KB KolibriOS program — no interpreter, nothing else to install.

Download kolibrios-apps.zip How to install

Graphite surfaces, soft corners, a hummingbird's sheen for an accent — and KolibriOS's own Tahoma.

How it's built

Python in, a KolibriOS binary out — thanks to plainpy.

Nectar is not a script running in an interpreter on KolibriOS. It is ordinary, statically typed Python — classes, closures, decorators, exceptions, f-strings — that plainpy compiles ahead of time into x86 machine code for KolibriOS. The result is a small MENUET01 executable you copy anywhere and start.

1

Python source

apps/nectar/ — the desktop — on top of lib/kui, a UI toolkit, and lib/kgfx.py, 32-bit graphics, both in Python too.

2

plainpy's compiler

CPython 3.14's grammar, then a typed compiler: plainpy --compile --target kolibri desktop.py. KolibriOS's system calls come from plainpy's own kolibri module.

3

fasm

The generated assembly becomes machine code; plainpy packs it the way KolibriOS's own programs are packed.

4

A native KolibriOS program

nectar — one file, started from autorun.dat like @TASKBAR. The same sources also run in plainpy's interpreter, and the tests run on Linux and macOS.

apps/counter/counter.py— the smallest kui program 
from kui import Window, window

count = 0

@window("Counter", 100, 100, 260, 160)
def counter(win: Window) -> None:     # paints the window
    win.bar(20, 30, 220, 20, 0x334455)
    win.text(24, 36, "Count: " + str(count))

@counter.button("+1", x=20, y=80)
def increment() -> None:
    global count
    count += 1
    counter.redraw()

@counter.on_key("q")
def leave() -> None:
    counter.close()

counter.run()

What's in it

It takes the place of @TASKBAR, @MENU and @ICON.

What it shows is the system's own: the programs come from menu.dat, the shortcuts from icon.ini, the notifications from @notify. Its own settings live in nectar.ini.

The taskbar

A button per window (activate, minimize, a menu), programs pinned and dragged along the bar, Win and Ctrl+Esc for the launcher.

Notifications

Every program's @notify becomes a toast in Nectar's look; it sinks into the bell by the clock, which keeps the list.

The notification area

The system's load, the volume, the network, the keyboard layout and the clock — each opens a flyout.

Run

A line with history and completion; paths with spaces, folders open in Eolite, documents with their program.

The desktop

icon.ini's shortcuts on the background layer, labels on translucent pills, dragged to another cell, the right button's menu.

Settings, and the default shell

Five accents, four text sizes, the tray's icons — and one button that makes Nectar the shell KolibriOS starts.

Notifications

The system's @notify, in Nectar's look.

A notification shows as a toast over the bar's right end — three at a time, the newest on top. It stays five seconds and one more a line (longer while the pointer is on it), then sinks behind the bar into the bell, which lights up with how many came. A click closes a toast at once; the ones above come down in its place.

Any program can send one — the way it always did

Nectar reads KolibriOS's own notifier's parameters. Make the default shell puts a program of some 150 bytes at /sys/@notify that hands them to Nectar (the system's notifier stays as /sys/notify3, for when Nectar is not running).

Maps

The world over https, on KolibriOS itself.

OpenStreetMap's map, or the Earth from space — EOxCloudless 2024, Sentinel-2's photos without the clouds — dragged with the mouse, zoomed with the wheel, and a search of places by name in the system's language. Every tile and every search comes over TLS from the internet: plainpy's requests and ssl, compiled into one KolibriOS program.

A kui window, the network between its events

Compiled programs have no threads, so the tiles come one at a time while no event waits — the nearest to the middle first, each a request on a connection kept open and a PNG or a JPEG decoded in PlainPy. The window answers between them; a tile not there yet shows a piece of a tile of the next zoom, enlarged.

apps/maps/osmmap/net.py— a tile
import requests

tiles = requests.Session()             # one TLS handshake, then a request a tile
tiles.headers["User-Agent"] = AGENT
r = tiles.get("https://tile.openstreetmap.org/12/2476/1280.png", timeout=20)
w, h, pixels = png.decode(r.content)

Install

Copy a folder, press one button.

Everything is in one zip: the programs, nectar.ini and how to install them. Try it first — starting nectar replaces the taskbar until the next boot.

  1. Download

    The latest release's kolibrios-apps.zip, or the programs one by one below.

  2. Copy it to a disk that stays

    Unpack it onto a disk KolibriOS keeps across boots — /hd0/1, a USB stick — with nectar, notify and nectar.ini in one folder. (In QEMU: make run shows build/kolibrios as /hd0/1.)

  3. Start nectar

    From Eolite, say. It ends @TASKBAR, @MENU and @ICON and takes their place for this session.

  4. Make it the default shell

    The bar's right button → Taskbar Settings → Startup → Make the default shell. Nectar rewrites /sys/settings/autorun.dat — its line where @TASKBAR's was, the lines of @ICON and @DOCKY gone, every other byte as it was — and routes @notify to itself. A notification tells you what it did.

  5. Save the system image

    KolibriOS's /sys is a RAM disk loaded from kolibri.img: RDSAVE opens on its own — save, and Nectar is there after a restart.

From the sources

Build it with plainpy and fasm.

Install plainpy (a .deb, an .rpm, a tarball, or its sources) and fasm, then make. The tests run without KolibriOS — offscreen, in the interpreter and compiled — and GitHub Actions publishes a release for every tag.

shell 
curl -LO https://github.com/c4simba/plainpy/releases/latest/download/plainpy_amd64.deb
sudo apt install ./plainpy_amd64.deb fasm
git clone https://github.com/c4simba/colibri-apps && cd colibri-apps
make                    # build/kolibrios: nectar, startmenu, notify, counter, files
make test               # the tests, compiled for this machine (TARGET=interp: in the interpreter)
make dist               # build/kolibrios-apps.zip
make run                # KolibriOS in QEMU with build/kolibrios as /hd0/1
